# Ondelia

An iOS and watchOS audiobook player for audiobooks imported from files or streamed and downloaded
from an [AudiobookShelf](https://www.audiobookshelf.org) server.

## Build

Requires Xcode with the iOS 26 SDK.

```sh
open Ondelia.xcodeproj
```

Run the `Ondelia` scheme. To run on a device, set your own development team in Signing & Capabilities.
