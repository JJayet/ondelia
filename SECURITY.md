# Security Policy

## Supported Versions

Only the latest Ondelia release on the App Store receives security fixes. Update the app before
reporting an issue.

## Reporting a Vulnerability

Do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/JJayet/ondelia/security/advisories/new).

Include the app version, iOS or watchOS version, steps to reproduce, and the impact. Issues involving
AudiobookShelf server credentials or Hardcover sign-in are especially welcome.

You can expect:

- An acknowledgement within 7 days.
- An assessment within 30 days, saying whether the report is accepted or declined, and why.
- For accepted reports, a fix in an App Store release, and credit in the advisory unless you prefer
  to stay anonymous.

Ondelia is maintained by one person in their spare time, so these are best-effort targets.
